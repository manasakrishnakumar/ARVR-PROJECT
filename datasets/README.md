# Datasets

## `sample/synthetic_reps.csv` (SYNTHETIC)
Generated by `backend/app/ml/synthetic_data.py` (`python -m app.ml.cli generate`). One row per repetition,
30 simulated participants, 6 classes. Labels come from the generating condition, **not** from human annotation.
It exists only to test the pipeline. Do not report results on it as evidence about real human movement.

## Bring your own real data
Provide a CSV with these columns (see `backend/app/ml/dataset.py`):

`participant_id, recording_id, exercise_id, label, source, rom_deg, duration_s, peak_velocity_deg_s, mean_speed_deg_s, extra_reversals, peak_progress, reliability`

- `label` must be one of: acceptable, insufficient_range, incomplete_repetition, too_fast, uncontrolled, insufficient_data
- `exercise_id` must match a file in `backend/app/exercises/definitions/`
- `source` should say where the data came from (e.g. `kaggle:<dataset-name>` or `own-recordings`)
- Features can be produced by running joint-angle series through `app/feature_extraction/features.py`.
- Splits are made by `participant_id`; you need at least 2 participants.

## Kaggle / public datasets
Not used yet. Before adding one: record its URL, licence, intended use and limitations in
`docs/dataset-documentation.md`, check that its labels actually map to the classes above (most public
exercise datasets label exercise *type*, not movement *quality*), and do not redistribute it unless the
licence allows. Downloading from Kaggle needs your own Kaggle account/API token.
